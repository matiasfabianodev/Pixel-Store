# Pixel Store 

Pixel Store es una tienda web de videojuegos de PlayStation 5 desarrollada como proyecto académico. Permite explorar el catálogo de productos, consultar sus detalles y gestionar el contenido según el rol del usuario.

## Tecnologías utilizadas
- HTML y CSS
- PHP
- MySQL
- Apache y XAMPP

## Características
- Catálogo de videojuegos con información detallada de cada producto.
- Paginación para navegar por el catálogo.
- Sistema de usuarios con roles de administrador y usuario estándar.
- **CRUD de productos:** creación, consulta, edición y eliminación de productos.
- Gestión de usuarios, incluyendo eliminación y modificación de roles.
- Control de permisos según el rol del usuario.
- Base de datos SQL incluida en el proyecto.
- Cuentas de prueba para verificar los distintos permisos.

## Instalación y ejecución
1. Instalar XAMPP y activar Apache y MySQL.
2. Copiar el proyecto en la carpeta `htdocs`.
3. Importar la base de datos incluida mediante phpMyAdmin.
4. Configurar la conexión a la base de datos según el entorno local.
5. Acceder al proyecto desde el navegador mediante `localhost`.
